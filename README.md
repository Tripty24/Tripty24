### [Internal AI Knowledge Platform](https://github.com/Tripty24/Internal-AI-Knowlegde-Platform)
A robust Retrieval-Augmented Generation (RAG) system that allows users to upload documents or code and query them using natural language. It processes and chunks text, stores vector embeddings for fast retrieval, and generates accurate answers using a Large Language Model.
* **Tech Stack:** Python, FastAPI, LangChain, ChromaDB, Google Gemini (LLM & Embeddings)
